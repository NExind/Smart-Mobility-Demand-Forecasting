# Model Artifacts Directory

## Overview

This directory stores the trained machine learning model bundle and associated cluster analysis files generated by `train_model.py` and `bike_demand_training.ipynb`.

The production artifact used by `main.py` is:
```
artifacts/bike_demand_model.pkl
```

---

## Artifact Contents & Architecture

`artifacts/bike_demand_model.pkl` is serialized using `joblib` and contains a complete, self-contained dictionary:

| Key | Object Type | Description |
|---|---|---|
| `artifact_version` | `int` | Artifact schema version (`2`) |
| `project_name` | `str` | `"Smart Mobility Demand Forecasting and Capacity Allocation"` |
| `target_name` | `str` | `"hourly_bicycle_trip_starts"` |
| `bike_vehicle_types` | `list` | `["classic_bike", "electric_bike"]` |
| `model` | `sklearn.pipeline.Pipeline` | `ColumnTransformer` + `HistGradientBoostingRegressor` |
| `cluster_preprocessor` | `sklearn.compose.ColumnTransformer` | `StandardScaler` + `OneHotEncoder` for K-Means context features |
| `kmeans` | `sklearn.cluster.KMeans` | 4-cluster K-Means model capturing time and weather context |
| `cluster_label_map` | `dict` | Maps cluster index to `"Contextual demand profile 1-4"` |
| `cluster_demand_means` | `dict` | Historical mean bicycle demand per cluster |
| `cluster_detail_stats` | `dict` | Distribution percentiles (P10, P25, P75, P90, std, min, max) |
| `cluster_label_style` | `str` | `"contextual"` (neutral naming reflecting weather/time context) |
| `baseline_by_dow_hour` | `dict` | 168-entry lookup of mean training demand for `(day_of_week, hour)` |
| `overall_training_mean` | `float` | Fallback mean demand across the training period (~$32.98$) |
| `mean_trip_duration_minutes` | `float` | Average bicycle trip duration (~$14.68$ min) for fleet turnover |
| `safety_buffer` | `float` | Planning buffer multiplier ($1.20 = 20\%$ safety buffer) |
| `station_share_lookup` | `dict` | Top 8 station pickup shares conditioned on `(day_of_week, hour)` |
| `global_station_shares` | `list` | Overall top station pickup shares (fallback) |
| `station_count` | `int` | Number of unique bike stations observed during training ($122$) |
| `model_numeric_features` | `list` | 17 numerical feature names for regression |
| `model_categorical_features` | `list` | 3 categorical feature names (`weather_code`, `season`, `demand_profile`) |
| `metrics` | `dict` | Chronological evaluation metrics on held-out test data |
| `holiday_lookup` | `dict` | Known public holiday calendar for input validation |

## File Size & Inclusion Justification

- **Size:** **733.6 KB** (0.72 MB).
- **Status:** Included in the repository.
- **Justification:** At under 1 MB, the model artifact is exceptionally lightweight and well within Git and GitHub recommendations (< 50 MB warning, < 100 MB hard limit). Including it enables immediate execution of the FastAPI backend (`main.py`) without requiring users to download 102 MB of raw data or run the training pipeline first.

---

## How to Regenerate the Artifact

To retrain and overwrite this artifact from the local dataset:

1. Ensure `data/a.csv` is present.
2. Run the training script:
   ```bash
   python train_model.py
   ```
   Or execute all cells in `bike_demand_training.ipynb`.
3. The new artifact will be validated and saved to `artifacts/bike_demand_model.pkl`.
